# 병장 혹한기 탈출 시뮬레이터

Java Swing을 활용해 제작한 병사 상태 관리 시뮬레이션 게임입니다.  
객체지향프로그래밍 과목 프로젝트로 진행했으며, 병사들의 만족도, 훈련 점수, 휴가 일수를 관리하면서 혹한기 훈련을 피하기 위해 휴가 20일을 모으는 것을 목표로 합니다.

## 프로젝트 개요

본 프로젝트는 사용자의 선택과 랜덤 이벤트에 따라 병사들의 상태가 변화하는 시뮬레이션 게임입니다.  
훈련을 진행하면 훈련 점수가 증가하지만 만족도가 감소하고, 일정 조건을 달성하면 휴가 일수를 획득할 수 있습니다.  
플레이어는 병사들의 상태를 관리하며 최종적으로 휴가 20일을 모아 혹한기 훈련을 피하는 것을 목표로 합니다.

## 개발 목적

- Java Swing을 활용한 GUI 게임 제작 경험
- 캐릭터 상태값 관리 구조 구현
- 사용자 입력에 따른 이벤트 처리 구현
- 랜덤 이벤트와 보상 구조 설계
- 게임 규칙이 실제 코드로 동작하는 과정 이해

## 주요 기능

- 병사별 만족도, 훈련 점수, 휴가 일수 관리
- 훈련 수행에 따른 상태값 변화
- 일정 훈련 점수 달성 시 휴가 일수 획득
- 야간 경계, 체력 단련, 전술 훈련 등 랜덤 이벤트 발생
- Java Swing 기반 GUI 화면 구성
- 버튼 입력 기반 게임 진행
- 게임 목표 달성 시 결과 출력

## 사용 기술

- Java
- Java Swing
- HashMap
- HashSet
- Array
- ActionListener

## 게임디자인 요소

| 요소 | 설명 |
|---|---|
| 목표 조건 | 휴가 20일 달성 |
| 상태값 | 만족도, 훈련 점수, 휴가 일수 |
| 리스크 | 훈련 시 만족도 감소 |
| 보상 | 훈련 점수 누적에 따른 휴가 획득 |
| 랜덤 이벤트 | 반복 플레이의 변수 제공 |
| 플레이어 선택 | 어떤 병사를 훈련시킬지 선택 |

## 본인 역할

- 게임 아이디어 구상
- 병사 상태값 구조 설계
- 훈련 및 휴가 보상 로직 구현
- 랜덤 이벤트 구조 구현
- Java Swing GUI 구성
- 프로젝트 발표 및 시연 준비

## 실행 방법

1. Java 개발 환경을 준비합니다.
2. `MilitaryLifeSimulation_6.java` 파일을 실행합니다.
3. 게임 화면에서 병사를 선택하고 훈련 및 이벤트를 진행합니다.
4. 휴가 20일 달성을 목표로 병사 상태를 관리합니다.

## 느낀 점

이 프로젝트를 통해 게임의 재미는 단순히 기능을 구현하는 것만으로 만들어지는 것이 아니라, 목표 조건, 상태값, 리스크, 보상, 랜덤 이벤트가 서로 연결될 때 생긴다는 것을 배웠습니다.  

특히 플레이어의 선택이 병사의 상태 변화와 결과로 이어지도록 설계하면서, 게임디자인은 아이디어를 구체적인 규칙과 시스템으로 만드는 과정이라는 점을 경험했습니다.  
또한 개발 경험을 통해 기획한 규칙이 실제 코드에서 어떻게 작동하는지 이해할 수 있었고, 이는 게임디자인 직무에서 개발자와 소통하는 데 도움이 되는 역량이라고 생각합니다.
