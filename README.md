# Military Life Simulation

Java Swing으로 구현한 **병사 상태 관리 시뮬레이션 게임**입니다.

전역까지 50일이 남은 말년 병장 4명을 관리하며, 혹한기 훈련이 시작되기 전 30일 동안 훈련 점수와 만족도, 휴가 일수를 조정해 **휴가 20일을 확보하는 것**이 목표입니다.

## 핵심 구현

- Java Swing 기반 GUI와 메뉴/버튼 이벤트 처리
- 병사 4명의 상태를 `HashMap`으로 관리
  - 만족도
  - 훈련 점수
  - 휴가 일수
  - 계급 정보
- 휴가 조건을 달성한 병사는 `HashSet`으로 별도 관리
- 훈련, 날짜 진행, 랜덤 이벤트에 따른 상태 변화
- 훈련 점수 10점 누적 시 휴가 1일 획득 및 만족도 회복
- 휴가 20일 달성 시 해당 병사를 휴가 상태로 전환하고 추가 훈련 비활성화
- 7일마다 랜덤 이벤트 발생
- 30일 진행 후 병사별 최종 결과 출력
- `javax.sound.sampled.Clip`을 이용한 BGM 재생 및 음소거 기능

## 기술 스택

`Java 17` · `Java Swing` · `AWT Event` · `HashMap` · `HashSet` · `Random` · `javax.sound.sampled`

## 게임 규칙

초기 상태는 모든 병사가 동일합니다.

| 상태 | 초기값 |
| --- | ---: |
| 만족도 | 100 |
| 훈련 점수 | 0 |
| 휴가 | 10일 |

병사별 **훈련 버튼**을 누르면 만족도는 3 감소하고 훈련 점수는 5 증가합니다. 다음 날로 진행할 때 훈련 점수가 10점 이상이면 10점을 사용해 휴가 1일을 얻고 만족도가 5 회복됩니다. 휴가가 20일 이상이 되면 해당 병사는 휴가 상태로 전환됩니다.

```text
병사 훈련
   ↓
만족도 -3 / 훈련 점수 +5
   ↓
다음 날 진행
   ↓
훈련 점수 10점 이상?
   ├─ Yes → 훈련 점수 -10 / 휴가 +1 / 만족도 +5
   └─ No
   ↓
휴가 20일 이상?
   ├─ Yes → 휴가 상태 전환 / 훈련 버튼 비활성화
   └─ No → 다음 날 계속
```

## 랜덤 이벤트

7일마다 아래 이벤트 중 하나가 발생하며, 휴가 중이 아닌 병사의 상태에 영향을 줍니다.

| 이벤트 | 상태 변화 |
| --- | --- |
| 야간 경계 | 만족도 -5, 훈련 점수 +3 |
| 체력 단련 | 만족도 +5 |
| 전술 훈련 | 만족도 +3, 훈련 점수 +5 |
| 단발령 | 만족도 -15 |

## 화면 및 메뉴 기능

메인 메뉴에서 게임 시작 외에도 병사 상태를 확인할 수 있도록 구성했습니다.

- `게임 시작`: 30일 시뮬레이션 진행
- `병사 스케줄 관리`: 휴가 중 / 훈련 대기 상태 확인
- `병사 만족도 확인`: 병사별 만족도 조회
- `휴가 관리`: 병사별 휴가 일수 조회
- `이벤트 발생`: 랜덤 이벤트 즉시 실행
- `음악 끄기`: BGM 중지
- `종료`: 프로그램 종료

## 상태 관리 구조

```text
soldierNames
     │
     ├── satisfactionMap  → 만족도
     ├── taskPointsMap    → 훈련 점수
     ├── leaveMap         → 휴가 일수
     └── rankMap          → 계급

onLeaveSoldiers (HashSet)
     └── 휴가 조건을 달성한 병사 관리
```

버튼과 메뉴 동작은 `ActionListener` 구현 클래스로 분리하고, 실제 상태 변경은 별도 메서드에서 처리했습니다.

## 실행 방법

Java 17 환경을 기준으로 작성했습니다.

```bash
javac -encoding UTF-8 -d out src/MilitaryLifeSimulation_6.java
java -cp out MilitaryLifeSimulation_6
```

원본 과제에서는 배경 이미지, 병사 이미지, BGM 파일을 함께 사용했습니다. 해당 미디어 파일은 외부 출처 자료가 포함되어 있어 현재 공개 저장소에는 포함하지 않았습니다. 원본과 같은 화면 및 BGM을 재현하려면 코드에 지정된 `src/images/`, `src/music/` 경로에 리소스가 필요합니다.
